# Task 1: Dockerized Web Application

## Objective
To create and run a simple web application using Docker.

## Technologies Used
- HTML
- Docker

## Project Files
- `index.html` — Webpage content
- `Dockerfile` — Instructions to build the Docker image

## How to Run
Build the Docker image and run the container using Docker Desktop.

## Outcome
The application is packaged as a Docker image and can run inside a Docker container.
